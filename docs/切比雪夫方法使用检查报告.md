### ⚠️ 需要注意的使用

#### 3. AUTOBN - BZ1策略成交量检测（第1069-1073行）
```python
self.calculate_chebyshev_probability(
    kline_volume_15[:-2],              # 所有历史成交量（除最后2根）
    max(kline_volume_15[-2:])          # 最后2根的最大值
)["chebyshev_upper_bound"]
< self.CHEBYSHEV_EXTREME_THRESHOLD  # 1%阈值
```
**潜在问题**：
- ⚠️ 使用 `max(kline_volume_15[-2:])` 包含了最后一根K线的信息
- 可能导致轻微的"未来数据泄露"

**建议修改**：
```python
self.calculate_chebyshev_probability(
    kline_volume_15[:-1],    # 除了最后一根的所有历史
    kline_volume_15[-1]       # 最后一根
)["chebyshev_upper_bound"]
< self.CHEBYSHEV_EXTREME_THRESHOLD
```

#### 4. AUTOBN - BZ1策略循环检测（第1082-1086行）
```python
self.calculate_chebyshev_probability(
    kline_volume_15[: index - 1],
    max(kline_volume_15[index - 1 : index + 1]),
)["chebyshev_upper_bound"]
< self.CHEBYSHEV_EXTREME_THRESHOLD
for index in range(-3, int(-len(kline_15) / 3), -1)
```
**潜在问题**：
- ⚠️ `index` 是负数（从-3开始），导致 `index + 1` 可能切片到意外的位置
- 例如：当 `index = -3` 时，`kline_volume_15[-3-1:-3+1]` = `kline_volume_15[-4:-2]`
- 当 `index = -1` 时，`kline_volume_15[-1-1:-1+1]` = `kline_volume_15[-2:0]` (空列表！)

**建议**：需要确认逻辑意图。如果是要检测历史上的突破点，建议：
```python
self.calculate_chebyshev_probability(
    kline_volume_15[: index - 1],
    kline_volume_15[index],  # 只比较单个点
)["chebyshev_upper_bound"]
< self.CHEBYSHEV_EXTREME_THRESHOLD
```

#### 5. AUTOBN - BZ2策略循环检测（第1120-1124行）
```python

    kline_volume_15[index - 2 : index],  # 前2根K线
    kline_volume_15[index],               # 当前K线
)["chebyshev_upper_bound"]
< self.CHEBYSHEV_SIGNIFICANT_THRESHOLD
```
**评价**：⚠️ 类似的负索引问题
- 当 `index = -1` 时，`kline_volume_15[-1-2:-1]` = `kline_volume_15[-3:-1]` ✅
- 当 `index = -2` 时，`kline_volume_15[-2-2:-2]` = `kline_volume_15[-4:-2]` ✅
- 逻辑上是对的，但需要确保索引范围正确

## 📚 阈值含义说明

- **适用场景**：检测非常罕见的极端事件（如暴涨暴跌）
- **数学背景**：当 k ≈ 10 时，切比雪夫上界约为 1%（数据偏离均值 10 个标准差）

### CHEBYSHEV_SIGNIFICANT_THRESHOLD = 0.25 (25%)
- **含义**：超出此范围的概率上界为 25%
- **适用场景**：检测显著但不是极端的异常（如明显的放量）
- **数学背景**：当 k = 2 时，切比雪夫上界为 25%（数据偏离均值 2 个标准差）
