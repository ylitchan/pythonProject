# 文件写入优化说明

> AUTOA 在 `autoTrade_pm.py` 中已改为显式初始化、批次结束后原子保存，详见 [AUTOA 状态流程](autoTrade_pm_AUTOA状态流程.md)。下文是旧版本的优化记录，不再作为当前 AUTOA 保存流程的依据。

## 问题描述
原代码在每次数据变化时都会立即写入文件,导致频繁的硬盘读写操作,影响性能。

## 解决方案
使用Python的`atexit`模块,将文件写入操作延迟到脚本退出时执行,无论脚本是正常退出还是异常退出。

## 修改内容

### 1. 添加atexit模块导入
在文件开头的标准库导入部分添加了`import atexit`

### 2. AUTOBN类的修改

#### 2.1 注册退出处理函数
在`from_cfg`方法中添加了退出处理函数的注册:

```python
# 注册退出处理函数,在脚本退出时保存数据
def save_on_exit():
    """脚本退出时保存alert_all数据到文件"""
    try:
        print(f"[{datetime.datetime.now()}] 脚本退出,正在保存数据到 {obj.alert_all_file}...", flush=True)
        with open(obj.alert_all_file, "w") as f:
            json.dump(obj.alert_all, f, ensure_ascii=False, indent=4)
        print(f"[{datetime.datetime.now()}] 数据保存完成", flush=True)
    except Exception as e:
        print(f"[{datetime.datetime.now()}] 保存数据失败: {str(e)}", flush=True)
        traceback.print_exc()

atexit.register(save_on_exit)
```

#### 2.2 移除立即写入逻辑
在`_rzq_market_impl`方法中(约第1483-1488行),将原来的立即写入代码:

```python
# 保存分析结果到文件
with open(self.alert_all_file, "w") as f:
    json.dump(self.alert_all, f, ensure_ascii=False, indent=4)
```

替换为:

```python
# 数据已更新,将在脚本退出时由atexit自动保存到文件
```

### 3. AUTOA类的修改

#### 3.1 添加退出处理静态方法
在AUTOA类中添加了静态方法:

```python
@staticmethod
def _save_alert_all_on_exit():
    """脚本退出时保存AUTOA的alert_all数据到文件"""
    try:
        print(f"[{datetime.datetime.now()}] 脚本退出,正在保存A股数据到 {AUTOA.alert_all_file}...", flush=True)
        with open(AUTOA.alert_all_file, "w", encoding="utf-8") as f:
            json.dump(AUTOA.alert_all, f, ensure_ascii=False, indent=4)
        print(f"[{datetime.datetime.now()}] A股数据保存完成", flush=True)
    except Exception as e:
        print(f"[{datetime.datetime.now()}] 保存A股数据失败: {str(e)}", flush=True)
        traceback.print_exc()
```

#### 3.2 注册退出处理函数
在AUTOA类定义之后,main函数之前添加:

```python
# 注册AUTOA的退出处理函数,在脚本退出时保存A股数据
atexit.register(AUTOA._save_alert_all_on_exit)
```

#### 3.3 移除立即写入逻辑
在`_monitor_stocks_impl`方法中,将原来的立即写入代码替换为注释。

### 4. 信号处理 (新增)

为了确保在命令行强制退出(如Ctrl+C)时也能保存数据,添加了信号处理机制:

```python
def handle_exit_signal(signum, frame):
    """处理系统退出信号，确保触发atexit"""
    signal_name = "SIGINT (Ctrl+C)" if signum == signal.SIGINT else "SIGTERM"
    print(f"\n[{datetime.datetime.now()}] 接收到退出信号 {signal_name}, 准备退出...", flush=True)
    # 调用 sys.exit(0) 会触发 atexit 注册的函数
    sys.exit(0)

# 注册信号处理
signal.signal(signal.SIGINT, handle_exit_signal)
signal.signal(signal.SIGTERM, handle_exit_signal)
```

## 优点

1. **减少硬盘IO**: 不再频繁写入文件,只在脚本退出时写入一次
2. **提高性能**: 减少了文件IO操作的开销
3. **数据安全**: 
   - `atexit` 处理正常退出和未捕获异常
   - `signal` 处理 Ctrl+C 和 kill 命令
   - 确保在各种退出场景下数据都不丢失
4. **代码简洁**: 移除了多处重复的文件写入代码

## 注意事项

1. 如果脚本被强制终止(如kill -9),atexit处理函数可能不会执行
2. 数据只在脚本退出时保存,运行期间的数据变化不会立即持久化
3. 如果需要在特定情况下立即保存,可以手动调用保存函数
