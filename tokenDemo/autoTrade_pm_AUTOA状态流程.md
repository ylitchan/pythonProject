# AUTOA 状态与处理顺序

适用于 `autoTrade_pm.py`，更新于 2026-09-08。本说明按实际执行流程记录；旧的开仓条件梳理、文件写入说明中与此不同的 AUTOA 描述不再适用。

## 初始化与保存

- 导入模块只定义模型、类和空状态，不读取业务 JSON，不注册退出保存和信号处理。
- `main()` 显式调用 `AUTOA.load_state()`，加载 `alert_all_A.json` 后再注册退出保存。单独使用 AUTOA 的调用方也应先显式加载状态。
- 盘中 `filter_stocks()` 只处理内存状态，不在每个监控批次结束时落盘。
- `push_daily_positions()` 完成每日账户/持仓信息推送后保存一次状态；即使推送失败，也会执行这次保存。
- 程序退出时由 `atexit` 直接调用同步的 `AUTOA.save_state()` 保存一次；主流程只负责停止调度器和清理异步资源。
- `save_state()` 在目标文件所在目录写临时快照，完整写入后原子替换。替换失败时旧文件保留；临时文件会清理。
- 保存先在当前执行线程完成一次 JSON 序列化，再整段写入；没有后台写任务，不会让较早快照覆盖较晚状态。
- 不迁移已有 BZ 数据，也不回补旧记录的历史最低价。

## 观察与开仓

1. 如存在 `reopen_pending_date`，根据该平仓日期查询第二个后续交易日。日历不可用时保留待确认状态，本轮不能重开。
2. 日历可用后写入 `earliest_open_timestamp` 并清除待确认日期；原有冷却、超时、同日观察限制继续生效。
3. 获取行情后统一刷新 BZ 状态。未出现 BZ 前保留入池价；普通行情在已有 BZ 时累计较低值；每次满足 BZ 条件均硬重置为当日最低价，并更新 `bz_reference_high`。
4. BZ 优先于 N。没有信号就返回；确认信号后才计算 ATR、成交量辅助阈值和建仓风控。
   ATR 必须是有限正数；NaN、正负无穷和非正值不生成持仓或开仓通知。
5. N 的初始止损复制观察 `price`；非 N 的初始止损仍按 ATR 计算。两者止盈仍按 ATR 计算。
6. 先同时写入持仓和观察记录，再发送信号和交易通知。

## 持仓、加仓与平仓

- 每轮取到行情后先更新观察状态，开仓当天仍不允许平仓或加仓。
- 判断已触发的止盈、价格止损和非 N 成交量止损；未触发时再算 ATR，判断首次止盈、DCA 或轨道调整。
- DCA 完成次数、均价和新止盈计算并写回持仓后才发送通知。N 持仓的止损始终固定，不跟随观察价或 ATR 轨道改变。
- 平仓先同步将平仓记录入队、删除持仓、在观察记录写入 `reopen_pending_date=平仓日期`，之后才发送通知。退出不再等待日历查询。
- 待确认的平仓日期随 JSON 保存，重启后仍能恢复冷却确认。实际交易日查询在下次观察处理时发生，避免错把周末/节假日算成交易日。
- 重启时无法取得交易日历，调度降级为仅处理已有持仓的退出，禁止观察入场和 DCA。使用有限的自然日历史窗口，并要求历史接口确认当日确有交易；只有旧日行情时跳过，避免节假日误处理。
- `monitor_stocks()` 在行情/通知超时后仍刷新平仓记录队列。线程已开始写入时，单次取消会等待写入结果确定后再释放锁，避免同一批因取消而再次写入。
- 程序退出时，JSON 保存失败不会跳过平仓记录刷盘和 HTTP 连接关闭，各清理动作独立完成并记录异常。

这保证的是任务取消和正常退出路径的一致性。进程被强制终止、断电，或磁盘持续不可写时，不承诺尚未刷盘的内存队列持久化；通知失败也不会自动重发。

## 行情与计算复用

- `_get_sina_daily_bar()` 用一次请求解析 OHLCV，供历史日 K 拼接和每日估值共用。实时请求失败明确返回不可估值，不经另一个方法再次请求同一接口。
- 已完成历史 K 线按代码、起止日期、周期和复权口径缓存；最新一根每次重新取。统一日期后排除重复的当日日线。
- 交易日历在同一天缓存，前序交易日和后续交易日共用。
- 同批待确认冷却的观察标的一起取得日历后再处理，批次内传递该快照，不逐标的重复请求；日历失败保留待确认状态到下一批。等待日历不占行情并发槽位，已有持仓和不需日历的观察可独立处理。
- 观察批次使用步长切片分配，五个批次合计覆盖同一观察快照；不再每轮强制完整垃圾回收。
- 两个市场共用 `_chebyshev_result()` 的结果计算，各自保留原有输入统计口径；零方差处理不变。
- AUTOBN ATR 保留 Wilder 平滑，AUTOA ATR 保留最近窗口平均，均保留原有上限；不能把两者合为同一种算法。
- AUTOA ATR 只计算最近 `period` 根 TR，并包含首根 TR 所需的上一根收盘价；不遍历最终结果不使用的历史。
