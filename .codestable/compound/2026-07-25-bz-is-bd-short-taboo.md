# AUTOBN 的 BZ 买入形态是 BD 做空禁忌

## 背景

重设计 AUTOBN 的 BD 做空入池条件时，曾考虑用“价格新高 + 成交量新高 + OI 切比雪夫极端”描述顶部。这个组合与 BZ 实盘买入逻辑在结构上相同：价格上涨、成交活跃、最新 OI 创窗口高位且相对历史基线极端，只是分析时使用日线粒度，实盘 BZ 使用 5m/1h 粒度。

## 结论

**BZ 的买入理由就是 BD 的做空禁忌。** 价格与成交量同时处于高位、且 OI 相对历史基线呈切比雪夫极端时，不能把“天价天量”解释成顶部耗尽并据此做空；该形态更可能代表新资金在高成本区集中进场、趋势仍有防守和延续能力。

BD 应避开新鲜资金成本位：OI 极端堆积可作为潜在清算燃料，但成交量峰值必须已经放旧。当前口径是量峰距今至少 3 天，再等待 OI 自峰值回撤 10% 确认杠杆开始清算。不要重新引入“当日或最近 3 日天量”作为 BD 入池的正向条件。
