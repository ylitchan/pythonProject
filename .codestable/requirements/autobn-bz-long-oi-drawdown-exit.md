# AUTOBN BZ 多头 OI 回撤退出

## 用户故事

- 作为运行 BZ 多头策略的人，我希望开仓依据明显衰退时及时平仓，而不是等市场热度完全回到长期常态。
- 作为策略维护者，我希望多头和空头的回撤幅度可以独立调整，避免一侧调参意外改变另一侧。
- 作为交易执行者，我希望行情数据暂时不可用时系统保持仓位，而不是因缺失数据误触发平仓。

## 为什么需要

BZ 会在持仓明显升温时开多，若仍用较早历史区间的平均水平作为退出线，往往要等本轮新增持仓大幅消失后才退出，无法及时识别这笔交易自身所依赖的高持仓结构已经衰退。

## 怎么解决

系统在每次 BZ 多头开仓时保存一条相对当时持仓水平的独立回撤线。持仓期间，一旦最新持仓水平回落达到设定幅度，就按持仓依据失效退出；无需等待账户多空结构提供额外确认。数据缺失时不触发该退出规则。

## 边界

- 只负责 BZ 多头持仓的 OI 回撤退出，不改变 BZ 的入池和开仓确认。
- 不负责 BD 空头的入池或扣扳机，两侧回撤参数相互独立。
- 不替代价格止盈、价格止损和其他持仓管理规则。
- 只对具备有效 OI 回撤线的多头持仓生效；没有有效回撤线的既有持仓不启用该规则。
