# 推送交易结果与失败提醒

## 用户故事

- 作为自动交易策略使用者，我希望开仓和平仓发生后立即收到重点清晰的移动端提醒，而不是只能查看运行日志或纯文本群消息。
- 作为币安自动交易使用者，我希望交易动作失败或因查询异常跳过时收到告警，以便及时检查账户和持仓状态。
- 作为 AUTOA 策略使用者，我只希望收到带 N 策略的开仓和平仓提醒，避免其他观察或策略信号造成通知噪声。

## 为什么需要

交易程序已经能发送企业微信消息，但纯文本层级有限，重要成交结果和失败原因不够醒目。交易发生后如果不能快速分辨市场、动作、标的、盈亏和原因，就容易错过需要人工介入的情况。

## 怎么解决

系统在交易成功或明确失败时发送结构清晰的移动端消息，把交易动作、标的、策略、成交结果、盈亏和失败原因分层展示。不同市场按各自边界筛选，通知渠道异常只记日志，不反过来影响交易。

## 边界

- AUTOA 只提醒包含 N 策略的成功开仓和平仓，不推送其他策略、行情异常或监控任务异常。
- AUTOBN 推送成功开仓、成功平仓，以及开仓失败、平仓失败和因持仓查询异常导致的跳过。
- 不改变企业微信消息内容和发送范围。
- 不把每日持仓汇总、观察信号或一般系统日志混入交易通知。
- 使用前需要通过运行环境或项目 `.env` 配置有效的消息推送凭证；本地凭证文件不进入版本控制。
