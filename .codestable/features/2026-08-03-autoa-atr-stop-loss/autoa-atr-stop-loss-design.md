# AUTOA ATR 止盈止损职责拆分设计

## 0. 需求摘要

AUTOA 设置独立的止盈、止损 ATR 倍数：止盈3.0，止损1.0。多头初始价格线及动态轨道均为 `hl2 + 3 ATR` 和 `hl2 - 1 ATR`。

## 1. 决策与约束

- 能力归属AUTOA现有价格风控，不新增持仓字段或模块。
- AUTOA只做多，因此上侧固定承担止盈职责，下侧固定承担止损职责。
- 初始价格线与持仓期间动态轨道共用同一对职责倍数。
- 不改ATR算法、DCA触发和专用止盈、成交量退出、盈利追踪、止盈衰减、AUTOBN及已有持仓迁移策略。
- 复杂度走默认档位，无新接口、状态或外部依赖。

## 2. 方案

### 2.1 名词层：现状 → 变化

**现状**：AUTOA以统一 `SUPERTREND_FACTOR = 3.0` 同时生成止盈、止损及动态上下轨。基准价100、ATR2时初始价格线为106和94。

**变化**：分别设置止盈、止损职责倍数3.0和1.0；相同输入变为止盈106、止损98。持仓继续保存绝对价格，不新增字段。

### 2.2 编排层：现状 → 变化

```mermaid
flowchart LR
  A[AUTOA获得hl2与ATR] --> B[上侧止盈线/轨 3 ATR]
  A --> C[下侧止损线/轨 1 ATR]
  B --> D[沿用既有开仓与持仓管理]
  C --> D
```

**现状**：开仓时直接用统一3 ATR生成两条价格线；持仓管理也以统一3 ATR生成上下轨，分别约束止盈收紧和移动止损。

**变化**：开仓和持仓管理分别使用职责倍数。既有触发顺序、DCA及追踪分支不变，仅下侧止损轨从3 ATR收紧至1 ATR。

流程约束：已有非零价格线不因版本发布自动重算；动态管理仍只能按既有规则收紧价格线；数据不可用行为不变。

### 2.3 挂载点

1. AUTOA止盈、止损职责常量。
2. AUTOA初始价格线职责计算。
3. AUTOA动态上下轨职责计算。
4. 数值与范围回归测试。

### 2.4 推进策略

1. 拆分职责常量并应用初始价格线；退出信号：100与ATR2生成106和98。
2. 应用动态轨道；退出信号：上轨3 ATR、下轨1 ATR且既有管理编排不变。
3. 补测试和全量验证；退出信号：相关测试、全量测试和Ruff通过，AUTOBN无行为改动。

### 2.5 结构健康度与微重构

`autoTrade_pm.py`偏大，但本次只替换AUTOA既有常量引用；拆文件风险高于收益。feature目录仅承载标准流程产物，不存在摊平问题；compound无相反目录约定。**本次不做微重构**。

## 3. 验收契约

1. 基准价100、ATR2时，AUTOA初始止盈106、止损98。
2. 持仓管理的动态上轨为106、下轨为98。
3. 调整止损倍数不改变止盈倍数，反向亦然。
4. 已保存持仓不会仅因发布自动重算。
5. ATR、DCA、成交量退出、追踪止损、止盈衰减和AUTOBN不变。
6. 相关测试、全量单测和Ruff通过。

## 4. 卸载与影响

删除职责常量并恢复AUTOA统一3 ATR初始价格线与动态轨道即可卸载，无数据迁移。预期影响是AUTOA新开仓初始止损及未进入盈利追踪时的动态止损轨更近，止盈空间保持3 ATR。
